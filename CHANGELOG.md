# Changelog

## 1.0.1 - 2026-10-28

- Updated repository metadata to match the manuscript
  "Recurrence and Primary Structure of Automorphism-Convolution Operators over Elementary Abelian 2-Groups".
- Added Svetlana A. Grigoryan's ORCID iD to `CITATION.cff`.
- Added explicit verification of the first augmentation-layer certificate
  `[eta_2]_1 != 0` for all 240 admissible Cauchy-Walsh shifts.
- Clarified that the hexadecimal binary kernels are selected representatives
  of recurrence signatures rather than canonical representatives.
- Preserved all previously reported Cauchy-Walsh and binary census results.
- Updated the SHA-256 manifest after reproducibility verification.
